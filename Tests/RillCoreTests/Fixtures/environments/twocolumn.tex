\begin{theorem}\label{thm}
The following are equivalent for a space that is long enough:
\begin{enumerate}
\item $X$ is compact and this item wraps around the line to be long.
\item every sequence converges.
\item something else.
\end{enumerate}
In particular it holds.
\end{theorem}
